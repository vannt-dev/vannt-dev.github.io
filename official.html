How to check a download

npm packages published from GitHub Actions carry provenance that names their vannt-dev repository (the package page on npmjs.com shows it). In a project that installed them:

npm audit signatures

Extension ZIPs attached to GitHub releases carry a build attestation:

gh attestation verify <file>.zip --owner vannt-dev

For an APK, compare the SHA-256 digest of the signing certificate with the one listed above:

apksigner verify --print-certs <file>.apk
