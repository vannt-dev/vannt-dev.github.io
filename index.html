AI coding agents

Junto

Workflow engine for Claude Code whose quality gates run real commands: a gate passes only on exit code 0, and the command, exit code and output are saved to disk as evidence. Plans need human approval. Advisory reviews can run on any OpenAI-compatible endpoint.

Claude Code pluginSiteCode

lane

One git worktree per task, so several coding agents work on one repository side by side. Slots are reused with their dependencies and build caches and held with a lease; the Android emulator, heavy builds and ports are shared one at a time, and lanes are checked together before and after each merge. With Junto, one table shows every lane's task.

reviewproof

A review ledger per pull request for AI code reviews over several rounds. It refuses what cannot be checked: a finding without a source, withdrawing a finding without new evidence, a verdict before the gates finish and every changed file is read (measured by a Claude Code hook), and a note posted without a named person's approval. It calls no model.

AI for testing

openapi-drift

Checks an OpenAPI document against your source code without running the API: reads the routes your NestJS, Express, Fastify, Hono or Spring code declares, compares them with the document and fails the build on drift in either direction, with SARIF output and pull request annotations. No AI, no build of your project.
